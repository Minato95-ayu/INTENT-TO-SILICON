# Getting Started

After building the VM and bootstrap compiler as described on the [Installation](/docs/1-getting-started/1-installation) page, create `hello.aayu`:

```aayu
let name = "AAYU"
print("Hello from " + name)
```

Run it from the repository root:

```bash
bin/aayu-vm run hello.aayu
```

The VM uses the `aayuc` executable located beside it to compile source files. The repository also contains BrainOS and Intent Engine Python prototypes; those are separate tools rather than commands built into the AAYU VM CLI.
