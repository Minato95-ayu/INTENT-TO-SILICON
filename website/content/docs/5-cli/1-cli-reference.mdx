# CLI Reference

The VM CLI currently supports these commands:

| Command | Purpose |
|---|---|
| `aayu-vm run <file.aayu> [--jit]` | Compile source with the nearby `aayuc` executable, then execute it |
| `aayu-vm run <file.ayc> [--jit]` | Execute bytecode |
| `aayu-vm build <file.aayu> [-o <file.ayc>]` | Compile source to bytecode |
| `aayu-vm --version` | Show engine version and platform |
| `aayu-vm --help` | Show CLI help |

Examples from the repository root:

```bash
bin/aayu-vm run tests/test_01_vars.aayu
bin/aayu-vm build tests/test_01_vars.aayu -o vars.ayc
bin/aayu-vm run vars.ayc
```

`build` outputs `.ayc` bytecode, not a native executable. The `--jit` flag currently falls back to the Rust VM because generated C has incorrect typed-value behavior. Commands such as `aayu pkg` and `aayu brain` are not implemented by this VM CLI.
