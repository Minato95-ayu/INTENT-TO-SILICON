# Syntax

AAYU uses keyword-delimited blocks. The current core syntax uses `let` for declarations, `if`/`else` and `while` for control flow, and `end` to close blocks. Statements do not require periods or semicolons.

```aayu
let count = 0
while count < 3
    print(count)
    count = count + 1
end
```

For the currently implemented subset and its limits, see the [language reference](https://github.com/Minato95-ayu/INTENT-TO-SILICON/blob/main/specs/language/v1/grammar.md) and [tests](https://github.com/Minato95-ayu/INTENT-TO-SILICON/tree/main/tests).
