# Demo App

This is a medium-sized application built natively in AAYU.

It demonstrates:
- Built-in Router (`main.aayu`)
- Reactive State Management (`AppState` and `LoginForm`)
- Local Storage API (`storage.get`, `storage.set`)
- Network Mocks (`services/api.aayu`)
- Components (`components/Navbar.aayu`)
- Forms and Validation (`pages/Login.aayu`)
- Theming via `aayu.json`
