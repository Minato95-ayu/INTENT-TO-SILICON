# Hello World

Save this as `hello.aayu`:

```aayu
print("Hello, AAYU!")
```

Run it with `bin/aayu-vm run hello.aayu` from the repository root after building the VM and bootstrap compiler. AAYU blocks use `end`; statements do not need periods or semicolons.

For more syntax, see the [Variables](/docs/2-language/2-variables) and [Functions](/docs/2-language/3-functions) pages.
