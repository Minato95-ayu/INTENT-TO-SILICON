# Roadmap

AAYU's development is broken down into three major phases.

## Phase 1: Core Language ✅
- Human-first Syntax
- Web Framework (Routing & HTTP)
- Database Operations
- Authentication

## Phase 2: Ecosystem 🚧
- **2A**: CLI & Package Manager ✅
- **2B**: VS Code Extension (Syntax Highlighting, Snippets) ✅
- **2C**: Language Server Protocol (Diagnostics, Autocomplete) ⏳
- **2D**: Standard Library Expansion

## Phase 3: Virtual Machine Runtime ✅ (v0.4.0 MVP Achieved)
- **3A**: Intermediate Representation (IR) & Bytecode Specification ✅
- **3B**: Stack-based VM Engine & Call Frames ✅
- **3C**: VM Standard Library Bridge (SQLite, Templates, JSON) ✅
- **3D**: Dynamic Web Route Dispatching & HTTP Socket Server ✅
- **3E**: Application Parity (Todo App & Library System) ✅

## Phase 4: Runtime Hardening 🚧
- Explicit HTTP routing verbs in grammar
- Connection pooling and filesystem lock prevention
- Stress testing & memory profiling
- Native Rust execution engine (Future transition)
