# Build a Todo App in 5 Minutes

In this tutorial, we will build a full-stack Todo application using AAYU's native database, forms, and routing capabilities.

## 1. Scaffold the Project

```bash
aayu new todo-app
cd todo-app
```

## 2. Define the Entity

AAYU has a built-in database. We define our data models using `entity`.

```aayu
entity Todo.
    text title.
    text status.
end.
```

## 3. Create the HTTP Routes

Let's create tasks to handle displaying and adding todos.

```aayu
task list_todos with req.
    todos is find all from Todo.
    show "todo_list.html" with todos.
end.

task add_todo with req.
    new_title is req.form.title.
    create Todo with title as new_title and status as "pending".
    return "<script>window.location.href='/';</script>".
end.

route "/" to list_todos.
route "/add" to add_todo.
```

## 4. Run the App

Start the server:
```bash
aayu run
```

You now have a fully functioning database-backed Todo application!
