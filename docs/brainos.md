# BrainOS

BrainOS is AAYU's architecture-generation intelligence layer.

## How it Works
1. **Decision Engine**: Reads parsed Intent IR to detect cross-domain constraints (e.g., "High Read Throughput" + "CRM").
2. **Recommendation Engine**: Selects the optimal software architecture (e.g., Edge-Cached Serverless Monolith).
3. **Cost Engine**: Projects monthly infrastructure costs based on the architecture.
4. **Security & Performance Review**: Scans the generated logical entities for vulnerabilities (PII) and performance bottlenecks.
5. **Project Scaffold Generator**: Writes the physical folder structure and initial .aayu code to disk.\n
