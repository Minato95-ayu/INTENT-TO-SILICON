# AAYU Engineering Roadmap

AAYU is structured around a long-term vision to build a modern full-stack programming language focused on simplicity, performance, security, and AI-first development. 

The core research novelty of AAYU is:
> **AAYU is a full-stack programming language that reduces software complexity by moving common application infrastructure (routing, CRUD, authentication, validation, APIs) from application code into the language runtime and virtual machine.**

## The 10-Step Macro Plan

1. ✅ **Core Language**
   - Syntax stable, Type system, Error messages, Standard Library

2. ✅ **Compiler**
   - Lexer, Parser, AST, Optimizer, Bytecode

3. 🟡 **Native Runtime** *(Current Target)*
   - C/Rust VM, Windows/Linux/macOS, No python.exe during execution

4. ❌ **Memory System**
   - Allocator, Garbage Collector, Thread safety

5. ❌ **Performance**
   - Bytecode optimizer, JIT, LLVM backend (optional later)

6. 🟡 **Developer Ecosystem**
   - Package manager (✅), Package registry, Formatter, Linter, Debugger, VS Code extension

7. ❌ **Self Hosting**
   - Compiler rewritten in AAYU, AAYU compiles AAYU, Python dependency removed completely

8. 🟡 **Research**
   - Benchmarks, Paper, Empirical evaluation, arXiv / conferences

9. 🟡 **Intent Engine** *(On Hold pending Language Maturity)*
   - Natural language → AAYU code, AI-assisted programming

10. 🔵 **Brain OS / Intent-to-Silicon** *(Long-term Vision)*
   - Human intent → executable system
