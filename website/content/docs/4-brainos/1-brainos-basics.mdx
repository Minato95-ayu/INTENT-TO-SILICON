# BrainOS Basics

BrainOS is a Python workflow/orchestration prototype in `brainos/`. It is separate from the Rust AAYU VM CLI: the current `aayu-vm` executable does not provide an `aayu brain` command.

The entry point accepts a goal argument:

```bash
python brainos/main.py --goal "Describe the project goal"
```

Review generated output before using it. BrainOS maturity and supported workflows should be judged from its implementation and tests; this page does not claim autonomous production readiness.
