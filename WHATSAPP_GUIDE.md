🔥 *AAYU LANGUAGE - QUICK START GUIDE* 🔥

Kya aapko AAYU try karna hai? Ye raha sabse simple tareeka! 👇

❓ *Kya Python ya Rust install hona zaroori hai?*
Nahi! Agar aap Windows par hain, toh aapko kisi bhi language (Python/Rust/Node.js) ki koi zaroorat nahi hai. AAYU completely *Zero-Dependency* aur *Standalone* hai! 😎

---

🛠️ *STEP 1: Download AAYU*
Bas niche diye link se ayuc.exe download karo aur apne PC mein kisi ek folder mein rakh lo.
🔗 https://github.com/Minato95-ayu/INTENT-TO-SILICON/releases/download/latest/aayu.exe

---

📝 *STEP 2: Code File Banao*
Usi folder mein ek nayi file banao aur uska naam rakho hello.aayu
Usme Notepad open karke ye code paste kar do:

\\\ayu
app MyFirstApp

action main
    print("=========================")
    print("🚀 Hello from AAYU!")
    print("=========================")
end

run main
\\\

---

🚀 *STEP 3: Run the Code!*
Usi folder mein address bar par click karke cmd type karo (taaki wahan Command Prompt khul jaye) aur ye command likho:

\ayuc.exe run hello.aayu\

BOOM! 💥 Aapka code milliseconds mein natively compile hoke run ho jayega!
