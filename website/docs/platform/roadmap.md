# Roadmap

AAYU's development roadmap outlines our commitment to building the world's first Intent Operating System.
Below is our quarterly vision for 2026.

## 2026 Q2 (Current) ✅

**Language & Runtime Core**

- ✅ AAYU Language Grammar (Lexer, Parser, Compiler)
- ✅ Virtual Machine (Python implementation)
- ✅ Entity & Relation System
- ✅ Role-Based Access Control (RBAC)
- ✅ Workflow & State Machine
- ✅ Intent Engine v4 (Native)
- ✅ Web Framework (HTTP, Routing, Sessions)
- ✅ Database Module (SQLite integration)
- ✅ Documentation Site

**Current Milestone**
- 🎯 Core language is production-ready
- 🎯 Intent Engine successfully generates full-stack applications
- 🎯 Community ready for early adopters

---

## 2026 Q3 (Next) ⏳

**Marketplace & Distribution**

- ⏳ **VS Code Marketplace**: Publish official AAYU extension
  - Syntax highlighting
  - Snippet library
  - Language support
- ⏳ **GitHub Linguist**: Official `.aayu` language recognition
- ⏳ **PyPI Release**: `pip install aayu-lang` official package
- ⏳ **Developer Documentation**: API guides and best practices
- ⏳ **Community Growth**: First public projects and case studies

**Expected Impact**
- Wider adoption through marketplace discovery
- Official language recognition on GitHub
- Seamless local development via PyPI

---

## 2026 Q4 (Future) 🚀

**Native Runtime & Advanced Features**

- ⏳ **Native Rust Runtime** (`aayu-rs`): High-performance VM
- ⏳ **Standalone Installers**: Windows, macOS, Linux binaries
- ⏳ **Package Manager**: Community package registry
- ⏳ **Language Server Protocol (LSP)**: Advanced IDE support
- ⏳ **Developer SDK**: Build custom libraries and extensions
- ⏳ **Demo Videos**: Visual tutorials and use cases
- ⏳ **Enterprise Features**: Teams, collaboration, cloud sync

**Expected Impact**
- Production-grade performance
- Reduced installation friction
- Professional developer experience
- Enterprise-ready ecosystem

---

## Beyond Q4 2026 🌟

**Long-term Vision**

- **Mobile Support**: Android & iOS runtime
- **Browser Support**: WebAssembly compilation
- **AI Integration**: Tighter Gemini, Claude, and GPT integration
- **Deployment Platforms**: Deploy to AWS, GCP, Azure
- **Community Marketplace**: Publish and share AAYU libraries
- **Foundation & Governance**: Open source foundation structure

## How to Contribute

AAYU is open source and welcomes contributions in:

- **Language features**: Add new syntax or optimize the compiler
- **Libraries**: Build community packages
- **Documentation**: Improve guides and examples
- **Testing**: Report bugs and write test cases
- **Tooling**: Contribute to VS Code extension, LSP, or build tools

See [Contribution Guidelines](https://github.com/Minato95-ayu/INTENT-TO-SILICON) for details.
