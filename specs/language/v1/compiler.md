# AAYU Compiler (v1)

Date: 2026-06-28
Status: Accepted

The AAYU Compiler is responsible for translating the Abstract Syntax Tree (AST) generated by the Parser into:
1. **AAYU Bytecode (`.ayc`)**: For execution in the AAYU VM.
2. **Architecture IR JSON**: For execution by Target Generators (e.g. React/FastAPI).

## AST to Bytecode Rules
- The compiler visits AST nodes in a post-order traversal to build the stack correctly.
- Variable assignments map exactly to `STORE_VAR`.
- Arithmetic expressions emit `LOAD_VAR` / `LOAD_CONST` followed by operators.
- `if` statements emit `JUMP_IF_FALSE` and unconditional `JUMP`.

## Single Source of Truth
No external client shall invoke the Compiler directly. All compilation requests must flow through the `AAYUEngine` interface.
