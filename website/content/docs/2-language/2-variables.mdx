# Variables

Declare a value with `let`, then assign to a declared variable to update it:

```aayu
let name = "AAYU"
let count = 1
count = count + 1
print(name)
print(count)
```

The current language examples infer value types from literals. Type annotations and `mut` declarations shown in older documentation are not part of the core syntax examples. See [the regression examples](https://github.com/Minato95-ayu/INTENT-TO-SILICON/tree/main/tests).
