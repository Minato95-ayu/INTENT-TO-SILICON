# Syntax Reference

AAYU is designed to be read like English. Statements always end with a period `.`.

## Variables and Assignments

Variables are assigned using `is` or `are`:

```aayu
name is "Ayush".
age is 25.
users are ["John", "Jane"].
```

## Control Flow

### If/Else Statements

```aayu
if age greater than 18.
    show "Adult".
else.
    show "Minor".
end.
```

### Loops

```aayu
for each user in users.
    show user.
end.
```

## Tasks

Tasks act like functions or handlers.

```aayu
task greet with name.
    return "Hello " + name.
end.
```

## Entities and Database

Declare tables using `entity`:

```aayu
entity User.
    text name.
    text email.
end.
```

Perform operations using `create`, `find`, `update`, `delete`:

```aayu
create User with name as "Alice" and email as "alice@test.com".
users is find all from User.
alice is find one from User where name is "Alice".
```
