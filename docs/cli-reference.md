# CLI Reference

The ayu command-line tool manages your entire workflow.

- ayu init <name>: Scaffold a new project.
- ayu run <file>: Compile and execute an .aayu script via the VM.
- ayu fmt <file>: Auto-format your code to the strict 4-space indent standard.
- ayu lint <file>: Run static analysis to catch missing types or terminating periods.\n
