# Runtime (AAYU VM)

The AAYU Virtual Machine executes the custom bytecode generated by the compiler.

## Stack-Based Execution
The VM (m.py) is a stack-based machine. Instructions push and pop RuntimeValue objects (e.g., NumberValue, TextValue) onto the stack.

## Deterministic Memory
AAYU utilizes Deterministic Automatic Reference Counting (DARC). There is no non-deterministic Garbage Collector pause. Memory is managed deterministically at compile time through scope analysis and reference tracking.\n
