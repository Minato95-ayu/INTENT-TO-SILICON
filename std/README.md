# Standard Library Sources: Status

Files in this directory are design drafts and algorithm sketches, not a verified standard library. The Rust bootstrap compiler supports basic user-defined actions, but the language still has no module import or package resolution. Therefore these modules cannot currently be imported and run as written.

Some comments promise native HTTP/TLS opcodes or cryptographic digests that are not wired to these AAYU functions. For the functionality that exists only in Rust, see `runtime_rs/src/`; that does not make it an AAYU standard-library API.
