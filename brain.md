# AAYU Project Brain

This document serves as an overview and knowledge base for the **AAYU** project (Intent-to-Silicon), summarizing its architecture, current status, and key concepts.

## 1. What is AAYU?
AAYU is an AI-native software engineering platform and programming language designed to let developers focus on application logic and design ("Intent"). The compiler handles all the heavy lifting, including UI rendering, state management, and native builds.

### Key Value Propositions
- **Intent-Driven**: Developers write clean, declarative pages and widgets without messy HTML/CSS/JSX spaghetti.
- **Built-in State Management**: State is a first-class citizen, eliminating the need for hooks like `useState` or external libraries like Redux.
- **Multi-Target Compilation**: A single codebase can compile directly to a Windows native executable (`.exe`) or a static Web App.
- **Zero Configuration**: Comes fully batteries-included with its own compiler, VM, package manager, and LSP.

## 2. Architecture & Pipelines
The AAYU architecture is currently frozen at **v1.0** and relies on two main tracks for execution:

### Track A: Software Factory (Web & Full Stack)
Transforms declarative intent into deployable full-stack software:
1. **AAYU Code** (`.aayu`) -> **Parser** -> **AST** -> **IR**
2. **Target Engine**: Selects the appropriate stack.
3. **Code Generators**: Generates React (Frontend), FastAPI (Backend), and PostgreSQL (Database) code.
4. **Orchestrator**: Bundles everything with Docker Compose.

### Track B: Native Runtime (Desktop)
1. **AAYU Code** -> **Compiler**
2. **AYC Bytecode** (`.ayc`)
3. **VM Runtime**: Executes the bytecode natively (Python/Rust VM implementations).

## 3. Project Structure
The project is built primarily in Python (Python >= 3.8) and is packaged as `aayu-lang`.
- `compiler/` - The AAYU compiler (Lexer, Parser, AST, Semantic Analysis, Bytecode generation).
- `runtime/` - VM implementation for executing `.ayc` bytecode.
- `tools/` - CLI and developer tools (e.g., `tools.cli:main` which maps to the `aayu` command).
- `intent_engine/` & `brainos/` - AI Agent orchestrator and intent interpretation.
- `.aayu` - Example and core standard library files written in AAYU syntax.

## 5. Development Guidelines
- **Language Evolution**: The core is frozen, but grammar, keywords, semantic passes, type system, and the standard library can be expanded additively.
- **Reflection**: Implemented as a read-only standard library module (`reflect_lib`) to ensure VM immutability and integrity.
- **Building**: The CLI uses `pyinstaller` under the hood to bundle standalone applications (`aayu build`).
