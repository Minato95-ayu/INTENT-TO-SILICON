# Packages

The current AAYU VM CLI does not expose a `pkg` command, and this repository does not document a stable remote package registry workflow. Older examples using `aayu pkg add` or `aayu.lock` are not current instructions.

Rust build dependencies are managed with Cargo for the toolchain itself. That is separate from package management for AAYU programs. See the [repository roadmap](https://github.com/Minato95-ayu/INTENT-TO-SILICON/blob/main/ROADMAP.md) for planned package work.
