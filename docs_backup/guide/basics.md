# Language Basics

AAYU is designed to read like plain English.

## Variables

```aayu
set "name" to "Ayush".
show "Hello " + name.
```

## Conditionals

```aayu
if age > 18 then.
    show "Adult".
else.
    show "Minor".
end.
```

## Tasks (Functions)

```aayu
task add_numbers with a and b.
    return a + b.
end.

set "result" to add_numbers(5, 10).
```
