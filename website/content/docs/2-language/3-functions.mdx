# Actions

The Rust bootstrap compiler supports actions with positional parameters, local variables, return values, and recursion:

```aayu
action add(a, b)
    return a + b
end

let result = add(2, 3)
print(result)
```

This example compiles and prints `5`. The regression suite also runs a recursive factorial action and checks that it prints `120`. Arguments must match the declared parameter count. Closures and named/default arguments are not implemented. See [Modules](./4-modules) for relative source-file imports.
