# Compiler Pipeline

The current command-line path uses the Rust bootstrap compiler and Rust VM:

```text
.aayu source -> aayuc -> .ayc bytecode -> bytecode verifier -> AAYU VM
```

The repository also contains a compiler pipeline written in AAYU under `compiler/`. That source pipeline and the bootstrap executable are distinct. A reproducible, byte-for-byte self-hosting bootstrap check is still unfinished in the [confidence report](https://github.com/Minato95-ayu/INTENT-TO-SILICON/blob/main/COMPILER_CONFIDENCE_REPORT.md).

The CLI currently routes `--jit` to the Rust VM because the experimental C emitter loses value types and has incorrect results. The benchmark-only `--sum` C-kernel measurement is not a VM JIT claim. AAYU does not currently compile through LLVM.

## Build and run

From the repository root, build both Rust components and keep their executables together in `bin/`:

```bash
cargo build --release --manifest-path runtime_rs/Cargo.toml
cargo build --release --manifest-path compiler_bootstrap/Cargo.toml
```

Then run `bin/aayu-vm run tests/test_01_vars.aayu`. See the [CLI reference](/docs/5-cli/1-cli-reference).
