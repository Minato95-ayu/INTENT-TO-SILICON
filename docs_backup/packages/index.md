# Official Packages

AAYU comes with an expanding ecosystem of official packages designed to simplify complex backend tasks into single lines of code.

- **[aayu-auth](/packages/auth)**: Native authentication, hashing, and session guards.
- **[aayu-http](/packages/http)**: Make external API requests natively.
- **[aayu-gemini](/packages/gemini)**: Connect your AAYU app to Google's Gemini LLM.
- **[aayu-ml](/packages/ml)**: Data Science and statistical logic natively processed in the VM.
- **[aayu-vision](/packages/vision)**: Computer Vision and image processing functions.

To import any package in an AAYU script, use the `use` keyword:
```aayu
use ml.
use auth.
```
