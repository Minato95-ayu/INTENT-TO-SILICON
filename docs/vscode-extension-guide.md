# VS Code Extension

The official AAYU VS Code Extension provides a seamless developer experience powered by the AAYU Language Server Protocol (LSP).

## Features
- **Syntax Highlighting**: Full grammar support for .aayu files.
- **Diagnostics**: Real-time linting errors (e.g., missing types).
- **Formatting**: Format document on save.

## Installation
Search for AAYU Language Support in the VS Code Marketplace or download the .vsix file from our GitHub Releases.\n
