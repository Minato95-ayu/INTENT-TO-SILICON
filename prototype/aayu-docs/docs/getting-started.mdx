# Getting Started with AAYU

Welcome to **AAYU**, a human-first architecture definition language and full-stack ecosystem. AAYU is designed to let you build complete web applications, databases, and APIs using natural, English-like syntax.

AAYU eliminates the boilerplate of setting up a web server, configuring an ORM, or managing routing. With AAYU, you declare your intent, and the runtime handles the rest.

## Why AAYU?

- **Human-First Syntax**: Read and write code that looks like an architectural blueprint.
- **Built-in Web Framework**: No need to install Express or Django; routing and HTTP are native to AAYU.
- **Native Database Support**: Define your data models with `entity` and use built-in keywords like `create` and `find`.
- **Package Manager**: Install modules effortlessly using the AAYU CLI.
- **Developer Tooling**: Full VS Code integration with syntax highlighting and snippets.

Next, check out the [Installation](/docs/installation) guide to get the CLI running on your machine.
