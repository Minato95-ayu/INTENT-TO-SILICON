Chapter 0: Introduction to AAYU & Intent Computing

1. What is AAYU?

AAYU is an Intent-to-Silicon programming language designed and built by Ayush Ghrit Kaushik. The fundamental goal of AAYU is to eliminate the friction that slows down developers and autonomous AI coding agents:

  • Eliminating Fragile Toolchains: Traditional stacks require complex build configs, package registries (npm/pip), and multi-directory boilerplate just to build a microservice.
  • Deterministic Execution: By using explicit end blocks instead of whitespace indentation, AAYU guarantees 100% syntactic clarity across all platforms, editors, and AI agents.
  • Zero Memory Corruption: Hardware-level 48-bit Nan-Boxing prevents pointer bugs, segmentation faults, and out-of-bounds memory corruption.

ðŸ” Silicon Deep Dive: How Hello World Executes
When you execute print("Hello, World!"):
  1. Lexer: Tokenizes the source into [Token::Print, Token::LeftParen, Token::StringLiteral("Hello, World!"), Token::RightParen].
  2. Parser: Emits an AST node: Statement::Print(Expr::StringLiteral).
  3. Emitter: Allocates string constant index 0 in the string table and generates native bytecode: PUSH_CONST 0 followed by opcode 81 (PRINT).
  4. Virtual Machine: Evaluates the Nan-Boxed pointer and outputs cleanly to stdout with zero class overhead.

ðŸ” The 256 Slot Limit: Why 256 Local Variables Per Function?
In AAYU, every function frame allocates exactly 256 indexed local slots addressed by a single byte (0..255). This design guarantees that local variable lookup is an instant array index with zero hashing overhead, providing maximum CPU L1-cache locality.
âš ï¸ Common Mistakes to Avoid
  • Semicolons: Do not write let x = 10;. Statements in AAYU are newline-delimited.
  • Unquoted Strings: Always wrap text in double quotes: let name = "Ayush".
  • 48-Bit Integer Range: Standard integer arithmetic operates within the signed 48-bit range (-140 trillion to +140 trillion). For scientific scales, use Floats.

Chapter 5: Functions & Actions

1. Function Declarations (action)

Functions in AAYU are declared with the action keyword. They can accept parameters and return values:

action compute_rectangle_area(w, h)
    let area = w * h
    return area
end

let result = compute_rectangle_area(12, 5)
print("Computed Area:", result) # 60

2. Recursive Functions

Actions fully support recursion with frame safety up to the virtual machine stack depth limit:

action fibonacci(n)
    if n <= 1
        return n
    end
    return fibonacci(n - 1) + fibonacci(n - 2)
end

print("Fibonacci(7):", fibonacci(7)) # 13

ðŸ† Problem 10: Two-Sum Target Matcher

action find_two_sum(arr, target)
