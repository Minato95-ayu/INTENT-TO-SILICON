# Installation

## Build from source

Install Rust and Cargo, clone this repository, and run these commands from its root:

```bash
cargo build --release --manifest-path runtime_rs/Cargo.toml
cargo build --release --manifest-path compiler_bootstrap/Cargo.toml
```

Place the resulting `aayu-vm` and `aayuc` executables together in `bin/` (add `.exe` on Windows). The VM looks for the compiler beside itself when it compiles a `.aayu` file.

```text
bin/aayu-vm run tests/test_01_vars.aayu
```

The repository's compiler and runtime require the Rust toolchain and declared Cargo crates. The website, editor extension, BrainOS, and Intent Engine have separate dependencies and setup instructions.

Windows users can also use [`install.ps1`](/install.ps1); Linux and macOS users can use [`install.sh`](/install.sh) to install the latest release archive. These installers place the VM and bootstrap compiler together so source execution can find both tools.

## What the build produces

`aayu-vm build file.aayu -o file.ayc` produces AAYU bytecode. It does not produce a native standalone executable. The `--jit` flag currently falls back to the Rust VM because generated C has incorrect typed-value behavior.
