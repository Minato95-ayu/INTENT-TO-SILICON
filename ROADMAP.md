# AAYU Public Roadmap

This roadmap outlines the major phases of AAYU's development as we transition from a deterministic intent compiler into a fully-fledged language ecosystem.

## Phase 1: Core Language ✅
- [x] Human-first Syntax (Keywords: `task`, `run`, `entity`, `show`, `if`, etc.)
- [x] Basic Runtime Interpreter
- [x] Built-in Web Framework (`route`, `serve`, HTTP Servers)
- [x] Native Database Operations (`create`, `find`, `update`, `delete`)
- [x] Authentication & Guards (`login`, `guard`)

## Phase 2: Ecosystem 🚧
- [x] **Phase 2A**: `aayu` CLI & Package Manager (V1)
- [x] **Phase 2B**: VS Code Extension (Syntax Highlighting, Snippets, Language Configuration)
- [ ] **Phase 2C**: LSP Support (Diagnostics, Basic Autocomplete)
- [ ] **Phase 2D**: Standard Library Expansion, Better Error Handling

## Phase 3: Native Runtime 🔮
- [ ] Transition from Python-based Interpreter to AAYU IR.
- [ ] Native compilation via LLVM or equivalent low-level toolchain.
- [ ] Cross-platform binary distribution.
