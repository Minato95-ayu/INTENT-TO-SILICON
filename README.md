## 💎 Canonical Language Specification & Syntax

AAYU is designed to be simpler than Python and read as naturally as spoken English:

### 1. The Core Syntax Rules:
* **Functions:** Declared with `action name(p1, p2) ... end` (NEVER `def` or `fn`).
* **Scoping:** All blocks close with `end` (NEVER curly braces `{}` or indentation-only).
* **Variables:** `let x = 10` for immutable constants, `state count = 0` for mutable state.
* **Output:** `print("...")` (NEVER `console.log`, `println!`, or `show()`).
* **Statements:** No semicolons (`;`) or trailing periods (`.`). Clean newlines.

### 2. A Complete Single-File Full-Stack Program:
```aayu

# 1. Built-in In-Memory Database Model (Crash-Persisted via WAL)
```

Solidity and the Ethereum Virtual Machine (EVM) have suffered over **$3.8 billion in smart contract hacks**, primarily due to **Reentrancy Bugs** (as seen in The DAO $60M drain and Euler Finance).

AAYU redesigns smart contracts from the silicon up using **Formal Invariants** and **State Mutex Guards** in pure AAYU (`std/chain.aayu` and `std/contracts.aayu`):
1. **Zero Reentrancy:** State mutex locks prevent external code from re-entering transfer routines before balance mutations are finalized.
2. **Mathematical Value Conservation:** Total currency in circulation is checked against a cryptographic invariant: $\sum \text{Balances}_{\text{after}} \equiv \sum \text{Balances}_{\text{before}}$. Value cannot be minted out of thin air.
3. **Gasless Silicon Register Speed:** Smart contracts execute natively at CPU register speeds without gas fees.
